# Algorithmic-Methods-of-Data-Mining
This is a repository for Algorithmic Methods of Data Mining discipline. It consists of all the projects and homework related to this subject.
To correctly read this repository you need to look at folders inside.
"homework 1" - is the main folder and in consists of first homework.Inside of it there are three folders, "problem1" - related to the first part of homework1 and has jupyter notebooks inside of it. Each notebook consists of a theme and all of the exercises related to this theme. 
"problem2" - second part of first homework and has impelentations of algorithms inside of it.
"pdf_with_submissions" - folder with a merged file inside. File consists of submission statuses of the all problems inside from the HackerRank site.
